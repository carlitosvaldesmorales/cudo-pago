# Comunicados institucionales de CUDO

Repositorio de contenido versionado para mensajes institucionales del Club Unión Deportivo Orilla. No es un backend ni una intranet nueva.

## Clasificación
- **PÚBLICO**: contenido aprobado para jugadores, socios, familias o comunidad, apto para sitio público y PDF.
- **INTERNO**: futura categoría para integrantes autorizados. **No almacenar contenido interno ni datos restringidos en este repositorio público.** Ubicación, roles y autorización requieren descubrimiento de intranet existente.

## Flujo editorial
BORRADOR_PARA_REVISION → APROBADO_POR_RESPONSABLE → PUBLICADO.
Conservar fecha, emisor, clasificación, versión y contenido fuente. El contenido publicado es una proyección, no segunda autoridad.
